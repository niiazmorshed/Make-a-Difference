## 🙌 About MAD

**Make a Difference (MAD)** is a modern Volunteer Management Platform built with the MERN stack. It streamlines the process of creating, managing, and participating in volunteer opportunities — enhancing the experience for both organizers and volunteers.

---

## 🛠️ Tech Stack

- **Frontend:** HTML, Tailwind CSS, Bootstrap, JavaScript, React.js  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** Firebase  

---

## 🌟 Key Features

1. **User Profile System** — Personalized dashboard and profile management  
2. **Secure Authentication** — Role-based access and protected routes via Firebase  
3. **Real-Time Updates** — Live updates and notifications for new opportunities  
4. **Volunteer Management** — Create, update, and track volunteer listings  
5. **Advanced Search** — Filter opportunities based on interest, date, or location
